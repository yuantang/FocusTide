# White Noise Audio Files

This directory contains white noise audio files for the FocusTide app.

## Required Files

The following audio files should be placed in this directory:

- `rain.mp3` - Gentle rainfall sounds
- `forest.mp3` - Forest ambience sounds
- `ocean.mp3` - Ocean waves sounds
- `fan.mp3` - Fan noise sounds

## Audio File Requirements

- Format: MP3
- Duration: At least 1 minute (longer is better for looping)
- Quality: 128kbps or higher
- Files should loop seamlessly

## Sources

You can obtain royalty-free white noise audio files from various sources:
- Free sound libraries like Freesound.org
- Royalty-free music sites
- Create your own recordings

Make sure to respect copyright and licensing requirements for any audio files you use.
