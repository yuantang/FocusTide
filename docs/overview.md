# 项目概述

## 🎯 项目简介

FocusTide 是一个现代化的开源番茄钟应用，运行在浏览器中，帮助用户通过结构化的工作和休息时间段来有效管理时间，提高生产力。

### 核心理念

- **简洁优雅**: 极简的用户界面，专注于核心功能
- **高度可定制**: 灵活的设置选项，适应不同用户需求
- **跨平台**: 基于 Web 技术，支持所有现代浏览器
- **开源免费**: MIT 许可证，完全开源

## ✨ 主要特性

### ⏰ 多样化计时器
- **传统计时器 (12:34)**: 精确到秒的经典计时器
- **近似计时器 (12 分钟)**: 分钟精度显示，减少干扰
- **百分比计时器 (50%)**: 显示完成百分比，保持专注

### 💡 简洁用户界面
- 极简设计，只显示必要控件
- 可自定义元素：
  - 日程概览
  - 智能待办清单
  - 颜色编码区段
  - 进度条

### 📑 灵活日程安排
- 可调节的会话长度，内置预设
- 可配置的长休息频率
- 计时器到期后继续跟踪时间

### 🎵 通知选项
- 区段结束时的声音提醒
- 桌面通知，支持后台监控

### ✅ 集成待办清单
- 区段特定任务（工作、休息、长休息）
- 在活动会话期间只显示相关任务
- 可选的自动任务清理
- 跨会话持久化

### 🌍 多语言支持
- 支持中文、英文、日文、韩文等多种语言
- 基于 Vue I18n 的国际化系统
- 动态语言切换

### 🔐 用户认证与同步
- 基于 Supabase 的用户认证系统
- 云端数据同步
- 跨设备数据一致性

### 🎨 主题系统
- 深色/浅色主题自动切换
- 自定义颜色方案
- 响应式设计

### 📱 PWA 支持
- 渐进式 Web 应用
- 离线功能
- 可安装到桌面/主屏幕

## 🏗️ 技术架构

### 前端技术栈
- **框架**: Nuxt.js 3 (Vue.js 3)
- **状态管理**: Pinia
- **样式**: Tailwind CSS
- **图标**: Tabler Icons
- **国际化**: Vue I18n
- **构建工具**: Vite

### 后端服务
- **认证**: Supabase Auth
- **数据库**: Supabase (PostgreSQL)
- **实时同步**: Supabase Realtime

### 开发工具
- **代码质量**: ESLint + Stylelint
- **类型检查**: TypeScript
- **版本管理**: Standard Version
- **包管理**: Yarn 4

## 📊 项目统计

- **代码行数**: ~15,000+ 行
- **组件数量**: 50+ 个 Vue 组件
- **支持语言**: 9 种语言
- **浏览器支持**: 所有现代浏览器
- **移动端**: 完全响应式设计

## 🎯 目标用户

- **学生**: 学习时间管理和专注力训练
- **知识工作者**: 提高工作效率和时间管理
- **自由职业者**: 项目时间跟踪和任务管理
- **任何需要时间管理的人**: 简单易用的番茄钟工具

## 🚀 项目愿景

FocusTide 致力于成为最好用的开源番茄钟应用，通过：

1. **持续改进用户体验**: 基于用户反馈不断优化
2. **扩展功能**: 添加更多生产力工具
3. **社区建设**: 建立活跃的开源社区
4. **跨平台支持**: 扩展到更多平台

## 📈 发展历程

- **v0.1.0** (2020): 项目启动，基础番茄钟功能

- **v1.5.0** (2023): 品牌重塑为 FocusTide
