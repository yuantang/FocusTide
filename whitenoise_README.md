# White Noise Audio Files

This directory contains white noise audio files for the FocusTide application.

## Available White Noise Types

1. **Rain** - Gentle rainfall sounds
2. **Forest** - Forest ambience with birds and rustling leaves
3. **Ocean** - Ocean waves crashing on the shore
4. **Fan** - Consistent fan noise
5. **Fireplace** - Crackling fireplace sounds
6. **Cafe** - Coffee shop ambience with quiet chatter and background noise

## How to Download the Audio Files

We've provided a script to download the white noise audio files from freesound.org. These files are licensed under Creative Commons and are free to use.

To download the audio files:

1. Make the script executable:
   ```bash
   chmod +x download_whitenoise.sh
   ```

2. Run the script:
   ```bash
   ./download_whitenoise.sh
   ```

3. The script will download all six white noise audio files to the `public/audio/whitenoise/` directory.

## Using the White Noise Feature

1. Open the FocusTide application
2. Click on the settings icon (gear icon) in the top right corner
3. Scroll down to the "White Noise" section
4. Enable white noise
5. Select your preferred white noise type
6. Adjust the volume using the slider (0.0 to 1.0 in 0.1 increments)
7. Choose whether to play white noise only during work sessions or all the time

The white noise will play in the background to help you focus during your work sessions.
